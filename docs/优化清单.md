# 优化清单（Backlog）

> 价值 / 成本为相对估计（★1~5）。标「必修」的是当前实现的缺陷。
> 当前代码状态：`score.py`（手填打分）、`collector.py`（8 分区排行榜，仅存 title+tname）、
> `recommend.py`（TF-IDF + 单一原型向量）、`serve.py`（每次刷新重算 Top 20 + 两档反馈）。

## A. 算法与特征（推荐准度）

| # | 项目 | 价值 | 成本 | 说明 |
| --- | --- | --- | --- | --- |
| A1 | **排除已打分视频** | ★★★★★ 必修 | ★ | 现在打过分（满意/踩雷）的条目仍会重复出现，且因成了正向样本反而更容易冒头 |
| A2 | **UP 主 / 作者特征** | ★★★★★ | ★★ | collector 的接口返回里有 `owner.name` / `mid`，目前**被丢掉了**。同一 UP 主的作品是最强信号之一（你的"历史调研室"效应） |
| A3 | **kNN 打分聚合**替代单一原型向量 | ★★★★ | ★★ | 预测 = 最相似的 K 条已打分视频的兴趣分加权平均。小样本更稳，且能处理"多峰口味"（历史 + 音乐 + 鬼畜并存时，单一原型会被平均稀释） |
| A4 | 正负双原型（Rocchio：正原型 − 负原型） | ★★★ | ★ | 比现在单一 `(score−3)` 加权更锐利 |
| A5 | 中文停用词表 | ★★★ | ★ | 现在"的 / 了 / 是 / 这个"等噪声词占着 TF-IDF 权重 |
| A6 | 字符 n-gram 特征（`char_wb` 2~4 与词级拼接） | ★★★ | ★ | 中文短标题在样本少时比纯词级更稳 |
| A7 | 预测分标准化 | ★★★ | ★ | 现在预测全挤在 3.8~4.0，排序区分度低；z-score 拉开 |
| A8 | 动态价值阈值 | ★★ | ★ | 固定 3.0 → 改为"过滤预测价值最低的 X%"（分位数） |
| A9 | 时间衰减 | ★★ | ★ | 半年前的打分降权，兴趣漂移 |
| A10 | **探索位 10~20%** | ★★★★ | ★ | 防回音室（方案里设计了但没实现） |
| A11 | 同 UP 主去重（≤2 条） | ★★★ | ★ | 防止整页都是一个 UP |
| A12 | 语义 embedding 升级（bge-small-zh / text2vec） | ★★★★ | ★★★ | 语义相似度明显优于 TF-IDF；模型走 hf-mirror 下载 |
| A13 | 标题党 / 情绪化标题惩罚 | ★★ | ★ | 规则或小模型，对应你最初说的"情绪输出、歪道事实" |
| A14 | 时长 / 播放量 / 新鲜度作辅助特征 | ★★ | ★★ | collector 已能拿到这些字段 |
