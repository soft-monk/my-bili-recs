## 1. 产品定位与目标

**一句话**：做一个只属于自己、由自己定义"什么值得看"的 B站视频推荐层。

**要解决的问题**
- 平台推荐以"停留时长"为目标 → 情绪化、标题党内容占优
- 隐式反馈（看了一眼就被当成喜欢）污染兴趣模型
- 优质内容被流量淹没，无法按"我认可的价值"排序

**产品目标**
1. 用户显式打分（**兴趣** + **价值** 双轴）作为唯一训练信号
2. 推荐可解释（能说出"为什么推给你"）
3. 数据完全本地留存、可回顾、可撤销、可跨机同步
4. 每日有边界（一天 10 个赞就够），不制造无限流

**非目标**
- 不做内容平台、不做社区（原方案 D）
- 不做多人 profile
- 起步阶段不引入深度学习模型（TF-IDF 足够）

## 2. 术语表

| 术语 | 含义 |
| --- | --- |
| 兴趣分 | 1~5，我喜不喜欢 → 决定**排序** |
| 价值分 | 1~5，值不值得看 → 决定**过滤** |
| 口味原型 / 质量原型 | 由全部打分加权得到的两个向量，用于预测候选的两轴得分 |
| 匹配度 | 0~100，当日候选池内归一化后的兴趣预测值，用于直观对比 |
| 每日清单 | 当天固定不变的推荐列表（`data/daily/YYYY-MM-DD.json`） |
| 探索位 | 相似度较低的候选，用于检验口味边界 |
| 域外探索 | **完全跳出当前 tag** 的候选（第 1.5 批 FR-1） |
| 三档反馈 | 喜欢 / 无感 / 踩雷（对应 5-4 / 3-3 / 1-1 分） |

## 4. 已评审待实现（第 1.5 批）

详见 [需求-推荐体验升级.md](需求-推荐体验升级.md)，三项关键决策已确认：

| 编号 | 需求 | 已确认的决策 |
| --- | --- | --- |
| FR-1 | **域外探索**（完全跳出当前 tag） | 每天 **1 条**；判定 = 相似度处于候选池最低 5% 且主分区不在已打过分区集合；连续 7 天点赞率为 0 → 自动降频为隔天 1 条 |
| FR-2 | **两列布局** | ≥1200px 两列 / <1000px 单列；按行左→右 |
| FR-3 | **每日 10 赞（目标制）** | 初始 14 条，可「再来几条」每次 +5，当天上限 30；**满 10 赞即提示达成并停止追加**；不足 10 赞也正常进入次日 |
| FR-4 | **全量记录** | 新增 `data/history.csv`；**只排除已反馈的**（点赞/无感/踩雷永久排除）；未反馈条目可再推荐，配 **3 天冷却期**（`--reshow-cooldown`，0=关闭） |
| FR-5 | **点赞列表页** `/liked` | 时间倒序 + 统计（累计/本周/UP 主/分区）+ 逐条撤销（撤销后回到候选池） |
| FR-6 | **页签导航** | 今日清单 `/` · 我的点赞 `/liked` · 全部记录 `/history` |

**建议实现顺序**：FR-4（记录层）→ FR-5 → FR-3 → FR-2 → FR-6 → FR-1（FR-1 依赖 collector 扩展）
